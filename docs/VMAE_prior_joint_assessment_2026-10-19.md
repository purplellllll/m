# VMAE 生成先验的联合评估

2026-10-19。探索性验证；对象为原始第 50 轮权重。训练权重不变。本报告将掩码重建、密码子频率基线和潜变量干预分开定义后联合解释。

## 判断规则

用户提出的三个问题应作为进入双空间优化试验的基础检查：

1. `masked_mutable_ce`：在遮挡的可变密码子位置，能否预测原始密码子。
2. `frequency_masked_ce`：仅由训练集同义密码子频率产生的基线。模型应在相同样本、相同目标位置优于它。
3. `shuffled_latent_ce`：破坏潜变量与原位置的对应关系后，解码是否变差。必须说明输入状态、打乱范围与评分位置，否则不能直接与 masked CE 相减。

三个条件可以支持“进入生成先验的下游试验”，不能单独证明潜在空间可稳定优化或生成 mRNA 的表达量更好。也不能把 shuffle CE 越大当成模型越好的单调指标：对扰动过度敏感同样可能产生很大的 CE。

同义合法性由当前输出硬约束保证，不能单独作为潜变量学习到有效生成规律的证据。评估时氨基酸条件始终保留，比较的是同义家族内部的选择能力。

原 `train.evaluate()` 中，`shuffled_latent_ce` 使用**未遮挡输入的 μ**，在 batch 内相同氨基酸的可变位置间打乱，评分覆盖全部可变位置。它应与 `clean_mutable_ce` 对照。5.686 对比 0.000940 支持干净输入重建依赖潜变量；不能直接把 5.686−0.976 当作掩码任务的潜变量贡献。

历史 `decoder_pilot_gate=true` 使用的也是上述 clean 潜变量干预，加上 5% 的频率基线改善等预设规则。它只是试验准入标记，不能作为生成先验已经完成下游验证的证明。

## 补充配对评估的方法

程序：[evaluate_prior.py](../latent_decoder/evaluate_prior.py)。复用现有模型、同义约束、数据校验、tokenizer、批处理与训练集频率计数，不改动训练代码或已有指标定义。

- 从固定验证集按 sequence_id 确定性选择 256 条，覆盖原始长度范围；与上一轮 256 条验证诊断使用相同抽样规则。
- 固定 batch=4、mask=15%、mask seed=173。模型使用 eval、z=μ；同一轮前向的 masked μ 用于潜变量干预。
- 模型、频率基线和打乱后的解码输出，均在**完全相同的被遮挡位置**计算 CE，按目标 token 数加权。
- 新增 `shuffled_masked_ce`，明确区别于历史 `shuffled_latent_ce`。在 batch 内同一氨基酸、同一遮挡状态内置换可变位置的 μ。已遮挡位置不会接收来自未遮挡位置的 μ，避免混入不同输入状态；PAD、单密码子家族与终止密码子位置保持不变。
- 重复三次置换，shuffle seed=9473，与 mask 随机数流独立，报告三次值及均值。置换允许少量位置保持原位，没有人为强制每个位置改变。
- 在本地 CPU 执行，只做推理；服务器上的其他任务不受本次评估修改。读取可信的本地保存 checkpoint；前后核验 SHA256。

两个配套测试已通过：置换保留氨基酸、遮挡状态与 PAD；对于显式去掉 z 依赖的模型，打乱前后 CE 差为零。

复现命令（输出文件必须尚不存在）：

```text
python -m unittest latent_decoder.test_evaluate_prior -v
python -u -m latent_decoder.evaluate_prior --checkpoint deliverables/vmae_50ep_last_epoch50_20261019.pt --data dataset --output docs/vmae_prior_paired_metrics_20261019.json
```

## 补充结果

结果以 [配对评估 JSON](vmae_prior_paired_metrics_20261019.json) 为准；记录包含样本 ID、种子、环境版本和权重校验值。

本地 CPU 评估完成，共 256 条 CDS、17,853 个相同掩码目标位置：

| 指标 | 结果 | 解释 |
|---|---:|---|
| masked_mutable_ce | **0.966981** | 正常潜变量下的掩码重建 |
| frequency_masked_ce | **1.140876** | 训练集同义频率基线 |
| shuffled_masked_ce，三次均值 | **1.189174** | 同输入、同目标位置的潜变量置换 |
| masked_mutable_accuracy | 56.15% | 模型准确率 |
| frequency_masked_accuracy | 42.89% | 基线准确率 |

模型 CE 相对频率基线改善 **15.24%**。打乱 μ 后 masked CE 平均增加 **0.222193**；三次置换分别为 **1.185739、1.187640、1.194142**，均高于正常模型 CE。

这一配对结果支持：模型具有超出简单同义频率的预测能力，且 masked 预测确实依赖潜变量与原位置的对应结构。结合历史完整验证结果，可以将其列为**具备基础证据的候选生成先验，进入下游对照试验**；尚未完成“适合双空间优化”的最终验收。

本次 CPU 与上一轮 GPU 使用不同设备随机数实现，即使 seed 都为 173，抽到的掩码也不相同。不能把本次 0.966981 与上一轮 GPU 抽样的 0.957077 当成模型退化；本次三项指标内部严格共享掩码。三次置换也不等于三个独立训练或掩码种子，不用于声称统计显著性。

原始第 50 轮 checkpoint 前后 SHA256 均为 `8009efdc3fc3ee61c82925b02feba600be3d6409f923838a612c26eb4af3d673`，没有参数更新。

## 如何进入下一阶段

若配对结果同时支持优于频率基线和潜变量参与 masked 预测，则可以把当前权重作为双空间优化的**候选生成先验**，进入受控下游实验。随后需要在相同起始 CDS、相同计算预算和同义约束下比较仅优化 z、仅优化直接空间 Δ、联合优化 z+Δ，并通过独立评估检查提升是否可迁移。

不得将重建 CE 改善直接解释成表达量改善，也不得只凭被优化预测器自身的分数判定最优 mRNA。当前阶段不启动新的训练或下游优化，不改动已保存的正式权重。

局限：新增评估是 256 条验证样本、一个掩码种子、三个置换实例，不是独立测试集结论。置换会破坏潜变量的上下文相关结构，CE 增加证明当前解码对该结构敏感，不能量化其全部因果贡献或证明潜在空间可平滑搜索。数据尚未认证近同源隔离；尚未执行 z/Δ 下游比较或表达实验。
