# DS-RiboDecode 双空间公式与实验设计审阅

日期：2026-10-16。范围：根据本轮提供的 `H=D(z)+αΔ`、残差与锚定正则、分阶段 α 开放和温度退火，审阅数学定义与实验设计。本文不实现序列设计代码，不启动训练。下述修正均为提案，不构成已经验证的创新。

## 判断

logit 残差方案可以形成可审查的实验，但当前不能把 α 单独解释为“直接空间贡献比例”。必须先明确合法坐标、softmax 的平移自由度、正则尺度以及相同候选初始化。建议固定 decoder、encoder 与评价模型参数，只优化 z 和 Δ；α 使用预先确定的日程，首轮不学习 α。

## 1. α 与残差惩罚不可分开解释

设效用最大化目标为 `F(softmax((D(z)+αΔ+M)/τ)) − λΔ RΔ − λN RN`。当 α>0，令实际 logit 残差 `r=αΔ`，则 `λΔ ||Δ||² = (λΔ/α²)||r||²`。因此，改变 α 同时改变了表达幅度与有效残差惩罚；不约束 Δ 时，小 α 也可能被大 Δ 抵消。α 是开关或尺度参数，不是概率混合权重，也不是可识别的生物学贡献。

在简化的无正则 SGD 中，r 的一步更新还含 α² 因子；Adam 的尺度适应并不能保证消除这一效应，尤其存在 epsilon、weight decay、动量状态与时间变化的 α 时。

最小修正：

- 固定 α 日程，报告 α、Δ 的合法中心化 RMS、实际 r 的 RMS、梯度范数与 λΔ/α²；α=0 时不计算这个比值。
- 先分别做固定 α 的敏感性和固定 α 的 λΔ 敏感性，避免直接进行大规模二者全组合搜索。
- 若意图是“逐步放开实际残差预算”，更清楚的替代是对实际 r 正则，并显式设置 r 的半径上限随阶段开放；此为后续替代消融，不与首版同时加入。
- 不能用 α 大小、Δ 范数或两个分支梯度比例作为模型机制已被解释的证据。

## 2. 合法 support 与平移自由度

对位置 j 定义合法集合 S_j、大小 k_j。softmax 对每个位置统一加常数不变：`softmax(h_j+c_j)=softmax(h_j)`。因此 residual 的常数分量没有预测意义，却可能进入正则、使不同实现的尺度不同。

建议只在有限合法 logits 上定义中心化残差：`Δc[j,i]=Δ[j,i]−mean(Δ[j,S_j])`，i∈S_j；非法位置置零，不参与范数；最后再添加 −∞ mask。不可在含 −∞ 的完整 logits 上求均值或做减法。k_j=1 的位置残差固定零，无需优化。PAD 不属于任何有效位置；终止位置的允许集合必须预先说明（固定原终止密码子，或允许三个终止密码子），各方法保持一致。

原 `||Δ||²/(L×64)` 的问题是：不可变位置、非法类别以及 padding 会稀释正则，不同蛋白的同义简并度不同也使其尺度不同。

提案采用 `RΔ=Σ_j Σ_(i∈S_j) Δc[j,i]² / max(1, Σ_j(k_j−1))`，只统计有效可变位置。这里分母对应中心化合法残差的自由度；也可以预注册“每位置先平均再跨位置平均”，但二者不能事后混用。批次先逐序列归一化再平均，避免长序列支配损失。

RN 可定义为有效 token 上 `||z−zref||²/(L_valid×d)`，排除 PAD；zref 在每次优化开始时固定并 detach。该项仍受 latent 不同维度方差影响，必要时使用在训练集固定估计的尺度，不能用待优化序列自身方差归一化。

z 与 Δ 的分解仍不唯一：decoder 输出改变可以被 residual 抵消。中心化只消除显然的平移自由度，不能使“latent贡献”与“direct贡献”完全可识别。因此效果以消融定义，不能由单次分解读出。

## 3. 温度与梯度共同变化

`p=softmax(h/τ)` 的 Jacobian 为 `(diag(p)−ppᵀ)/τ`。降温在非饱和区域提高局部尺度，同时可能使概率饱和、梯度接近零；不能笼统说降温必然增强梯度。残差相对于概率的尺度由 α/τ 共同决定。若把有效残差写成 `v=αΔ/τ`，固定 τ 时其惩罚系数正比于 λΔ τ²/α²。

最小修正：先固定温度验证残差是否有效，再单独加入温度退火；记录分布熵、最大概率、soft 与 argmax 后 hard 效用差、合法梯度范数。不要在同一阶段同时快速增 α 和快速降 τ，否则无法区分改进来源。直接与潜空间基线使用相同温度日程和 hard candidate 提取规则。

## 4. 相同初始化与训练准备门槛

Δ=0 且 z=zref 时，起点是 D(zref) 解码得到的分布，不保证等于原始 CDS；AE 重构误差不可被误算作 latent 搜索收益。

几何公平对照：先获得同一个初始合法分布 p0。latent 从一个固定 z0 开始；hybrid 用同一个 z0 且 Δ=0；direct 的 logits 从相同 decoder 有限 logits 初始化，保证同一温度下 p0 相同。latent→direct 顺序法在交接时继承同一候选分布，而非重置到额外优质序列。原始 WT 分数另行保留。

如果另外要比较“从完全相同 WT 开始”，必须确认 decoder 可足够准确重构该 WT，或公开采用非零 Δ0 抵消重构误差，并另行说明它改变了起始残差预算。不要声称任意 WT 都能被有限 decoder 精确表达。

准备 decoder 时：报告合法可变位置准确率、masked 位点准确率、CE、latent-shuffle/打乱 token latent 的性能下降及 hard 重构变化；Met/Trp/固定 stop/PAD 不应抬高主要准确率。clean identity 不要求全长 exact-match 100%。若打乱 z 后 decoder 几乎无变化，则尚不能支持潜空间分支具有实质作用。小 VMAE 的 q(z|x) 标准差、KL/token/dim、posterior collapse 也需要记录。

## 5. 最小消融及公平预算

最少比较：direct-only、latent-only、hybrid、latent→direct；共享 frozen scorer、MFE surrogate、同义 mask、目标缩放、初始化分布、候选数上限及选择规则。

核心消融依次为：有无 residual；有无 RN；固定 α vs 分阶段 α；固定 τ vs 退火 τ。不要一次加入多个新部件后把全部收益归因于双空间。

同时报告 scorer forward/backward 次数、decoder 调用次数、wall time、峰值显存、unique hard candidates 与 RNAfold 标签预算。相同 iterations 不等于相同计算预算。阶段方法共用总预算，不能每阶段都获得完整单方法预算。建议既提供匹配 scorer-query 的主比较，也提供相同 wall-time 的成本比较；同配置重复种子并以蛋白为统计单位，不能把每步候选当独立样本。

预先冻结 hard-candidate archive 和选择规则；RNAfold 必须参与约束筛选而非仅被计算和报告。保留跨轮 archive，避免默认最后一轮就是全局最佳。

## 6. 评价器盲测

训练/开发集用于选择 α、λ、τ 和 checkpoint；测试蛋白及其同义变体不能用于调参。多次查询后根据外部评价器挑方法，该评价器就成为开发评价器，不能继续叫盲测。

冻结至少一个从未进入梯度、候选 gate 或超参选择的独立评价器，在测试候选全部确定后批量评价；记录其训练来源与蛋白重叠。不同架构但同源训练标签的预测器不构成独立真实生物学验证。RNAfold 是热力学计算复核，非蛋白表达测量。

主要结论应基于独立评价器上的约束可行率、相对共同起点的 hard 效用变化、Pareto 表现、soft→hard 落差及成本。没有新湿实验时，只能声称计算评价改进，不能声称蛋白表达已提高。

## 7. 建议的起始参数范围（全部为提案）

前提：效用及正则采用上述固定归一化，并在开发集固定目标尺度。下列是小规模敏感性范围，不是已经校准的默认，也不移植为论文参数。

| 参数 | 小规模起点/范围 | 理由与限制 |
|---|---|---|
| α | 起始0；固定对照0.1、0.3、1；主日程后期到1 | 以合法中心化 decoder-logit 的开发集尺度报告；α不能单独比较贡献 |
| λΔ | 0.01、0.1、1，先固定 α=1 | 正则已按合法自由度归一化；若效用未标准化不可照搬 |
| λN | 0、0.001、0.01、0.1 | 先定位是否发生latent漂移；不同 latent 尺度须重新校准 |
| τ | 先固定0.5或1；再比较0.5→0.1；0.03仅敏感性对照 | 避免初版直接低至0.01引发饱和；不是断言0.01不可用 |
| 优化阶段 | 前40%仅latent；中间40%开放α；后20%共同优化 | 先不让α快速开放与τ快速降低重合；比例是试验提案 |
| 学习率 | z：1e-4、1e-3；Δ：1e-3、1e-2 | 两空间尺度不同，需独立记录更新RMS；未实测收敛 |

建议先做极小无生物结论的数值验收，再决定大训练。失败条件包括：残差完全绕过 decoder、只有soft分数上涨、独立评价无收益、temperature饱和、重构偏差主导、RN只把搜索锁死，或等预算顺序方法已达到相同效果。出现这些情况应简化方案，不应增加更多融合权重掩盖问题。
