# V4 完整隐空间优化、独立 seq2ribo 与条件追加五轮

当前启动的是独立实验，不覆盖已经完成的V4三轮训练或历史V3。

## 固定比较

- 复用原微调的24条固定VAL，按同一CDS身份比较V3及V4 epoch1、2、3。
- 每个权重、每条CDS执行完整80步隐空间优化：Adam LR0.05，标准化半径8，同义密码子约束，起始和stop固定。
- 同一条CDS在不同权重上使用相同随机种子。优化奖励保持 `Hard + R_GC + R_CAI + R_MFE`，不增加新权重、不在测试集上调参。
- MFE每10步提供真实RNAfold/SCST反馈；最后对全部唯一归档候选精确折叠，按完整组合奖励锁定候选。
- 候选锁定并落盘后才运行独立seq2ribo：沿用官方HEK293 CDS-only TE、3个固定种子、每种子8次sTASEP。seq2ribo不参与优化、选候选或追加训练判定。
- 另在原30条对照面板评估V3、epoch3，以及VAL胜出权重（若不同）。这30条此前已被探索，不能称为新的未使用测试集。

24条VAL×4个权重共96次完整搜索，另有24条亲本独立评分，共120行验证指标。30条面板至少60次搜索、90行指标；若较早轮次胜出，还补充该轮30条搜索。

RNAfold结果使用跨权重的共享SHA缓存。所有命中都按版本、37°C、dangles2、能量/长度一致性核验；记录每次搜索的新物理折叠数和缓存辅助耗时。不同模型的耗时不直接解释为模型固有速度差异；相同步数也不等于完全相同的查询数。

## 追加五轮的判定

等上述完整优化和独立评分完成后，用同一24条VAL的**优化后组合奖励均值**比较epoch0–3（epoch0代表V3）。只接受完整、身份一致、有限值的比较；缺失任何一条就不触发。

若epoch3达到最高均值，则从其完整训练状态继续epoch4–8，共追加5轮。差值在1e-8内视为数值并列，并列时选较晚轮次。若较早轮次或V3胜出，不追加训练，如实记录排名。

追加训练恢复epoch3的模型、AdamW状态、Torch CPU/CUDA及Python RNG，保持LR1e-5、batch4、相同数据划分、相同24条VAL和原奖励设置。新目录单独保存，不重跑前三轮。

epoch4–8每轮都保存独立模型文件，并继续按原固定VAL训练目标选择best。五轮结束后，对该验证选中权重再次做完整隐空间优化及独立seq2ribo，和epoch3/V3作同身份比较。这里区分“训练验证目标选中的best”和“完整优化后的排名”，不声称已经枚举比较所有新增轮次的优化效果。
