# V3与V4第六轮：模型核验与新搜索协议

V3多指标搜索使用原V3权重，并非另一套模型。V3检查点为原训练第42轮；V4第6轮为额外多目标微调阶段的第6轮。两者均为2,498,240参数，编码器/解码器各6层，宽度128，8头，潜变量256。158/159个状态张量不同。详细权重哈希见model_identity_audit.json。两阶段训练目标不同，objective数值不能直接比较。

本轮使用冻结权重，不重新训练。按用户选择，仅把原搜索中的RiboDecode奖励替换为自有评分器，保留GC、CAI和MFE奖励：

reward = own_score + (GC_fraction-GC_original)/0.05 + (CAI-CAI_original)/0.05 + (MFE_original_per_nt-MFE_candidate_per_nt)/0.05

三个性质奖励无截断，参考点均为原始CDS。自有评分器使用冻结gated_graph及mRFP c读出，种子30101、30102取均值。分数单位改变后，各项相对影响也会改变；联合奖励上升不保证自有分数上升，报告会同时列出分项。

固定同一30条CDS、每条80次潜空间提案；保持氨基酸和起止密码子。旧多指标终点只作为比较对象，不用于初始化或保底。原始CDS纳入保底。V3和V4分别完整搜索，并独立评估RiboDecode、seq2ribo、GC、CAI、MFE。历史纯自有分数搜索另外列出，不冒充本轮新结果。

本地CPU按V3搜索→V3评估→V4搜索→V4评估→独立审计与汇总串行运行，每次2个Torch线程。失败即停止，不自动重试。参考上一轮约5小时搜索耗时，两轮完整搜索可能约10小时，另加评估；实际取决于候选长度及缓存命中，非完成时间承诺。
