# LR=0.0001，5 epochs，新服务器独立实验

正式模型：Encoder/Decoder 各 6 层，hidden 512，8 heads，FFN 2048，latent 256，RoPE，显式 AA 条件，38,302,784 参数。使用同一冻结 dataset：train 35,710，val 3,949，test 4,342；test 不参与模型选择。数据未完成近同源隔离认证，仍按开发实验处理。

从零初始化，seed=20261016，lr=0.0001 恒定，5 epochs，无早停；batch=4，梯度累积=8，FP32，AdamW weight decay=0.01，梯度裁剪=1。其余参数与先前 0.0001 实验一致：25% clean batch，其余 15% mask，Full/Masked CE 权重均为 1；KL 最终 β=0.001，前 20% optimizer steps warm-up。

本次只补充日志字段，不改模型、随机采样、损失或更新规则。窗口日志除真实混合总 loss 外，还记录 `full_ce`、`masked_ce`、`kl_per_token`、`weighted_kl`、`clean_batches`、`masked_batches`、`masked_batch_fraction`、`clean_mode_loss`、`masked_mode_loss`。某模式在窗口中没有出现时，其模式均值为 null。Full/Masked CE 字段是所有 microbatch 的窗口均值，含 clean batch 的零 masked CE；`weighted_kl` 是窗口内实际 β×KL 的平均，不能用窗口末 β 代替整个窗口的 β。

部署包包含全部代码、配置和完整冻结数据。服务器解压并启动：

```bash
tar -xzf ds_ribodecode_lr_0001_5ep_2026-10-18.tar.gz
cd ds_ribodecode_lr_0001_5ep_2026-10-18
sha256sum -c SHA256SUMS
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
nohup bash latent_decoder/run_server_lr_0001_5ep.sh > lr_0.0001_5ep.log 2>&1 < /dev/null &
tail -f lr_0.0001_5ep.log
```

启动会做数据校验及最长 batch 前后向预检，实际训练中每个完整 epoch 保存 last.pt、验证最佳 best.pt 和 metrics.jsonl。已有输出目录会拒绝新开训练。恢复已中断任务时，使用该 run 的配置及 last.pt：

```bash
bash latent_decoder/run_server_lr_0001_5ep.sh --resume runs/vmae_lr_0.0001_5ep/last.pt
```

所有结果位于 `runs/vmae_lr_0.0001_5ep/`。不要以短窗口混合 loss 是否单调下降判断是否学习；同时看分项、模式占比和固定验证指标。本包是训练准备，不附带预先假定的最终表现或训练耗时。
